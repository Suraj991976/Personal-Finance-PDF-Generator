# 💰 Personal Finance PDF Generator

### Automated Financial Report & Educational PDF Generator

**Personal Finance PDF Generator** is a Python-based document automation project developed by **Suraj Baranwal**. It uses **ReportLab** to dynamically generate professionally formatted personal finance reports and educational materials in PDF format.

The project focuses on **financial data processing, automated calculations, document generation, layout formatting, and professional PDF presentation**.

## ⚙️ How It Works

The application follows a simple automated workflow:

```text
Financial Data
      ↓
Data Processing
      ↓
Expense Calculation
      ↓
Savings Calculation
      ↓
Report Generation
      ↓
Professional PDF
```

The program takes financial information such as income, expenses, and savings goals, processes the data, and generates a structured PDF report.

---

## 📊 Financial Calculations

The application automatically calculates:

### Total Expenses

```text
Total Expenses = Sum of All Expenses
```

### Savings

```text
Savings = Income - Total Expenses
```

### Savings Percentage

```text
Savings % = (Savings / Income) × 100
```

### Savings Goal

The generated report compares actual savings with the predefined savings goal and displays whether the goal has been achieved.

## 💻 Installation

Make sure Python is installed on your system.

Install the required dependency:

```bash
pip install reportlab
```

Or:

```bash
python -m pip install reportlab
```

---

## ▶️ Run the Project

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Personal-Finance-PDF-Generator.git
```

Move into the project directory:

```bash
cd Personal-Finance-PDF-Generator
```

Run the Python program:

```bash
python personal_finance_pdf.py
```

After successful execution, the application generates:

```text
personal_finance_report.pdf
```
